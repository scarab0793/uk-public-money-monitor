Data integrity notice

This site does not display invented government spending figures. Every dataset is imported from an official publisher and links to its source. Coverage differs between modules and is stated in each section; estimates, budgets and contract values are never presented as actual spending.

Data sources and methodology

Every figure on this site comes from an official publisher and links back to it. Imports run automatically on GitHub Actions; a failed import never replaces the last good data. Different measures (cash receipts and accrued revenue, budgets and outturn, contract values and payments, nominal and real terms) are kept apart and never added together. Processed data can be downloaded from the links below under the Open Government Licence.
